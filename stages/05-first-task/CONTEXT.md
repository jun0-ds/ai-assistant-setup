# 7. 첫 작업과 정리

## 입력

| 자료 | 범위 | 이유 |
|---|---|---|
| [작업공간](../../references/workspace.md) | 생성·완료 | 실제 파일 관리 |
| 작업공간 `CONTEXT.md` | 현재 범위 | 업무·개인과 프로젝트 선택 |

## 진행

1. 사용자가 요청한 실제 작은 일 하나로 시작합니다. 회사·개인 자료를 필요 이상으로 요구하지 않습니다.
2. 업무/회사 또는 개인 아래에 프로젝트·이슈 폴더를 만듭니다. 일반 폴더도 하나의 작업 단위입니다. 작업공간 맨 위에 파일을 흩어 두지 않습니다.
3. 프로젝트 CONTEXT에 목적·상태·필요한 입력·진행·결과 위치를 적고 상위 인덱스에 연결합니다. 자료·결과·임시 폴더는 필요할 때 만듭니다.
4. 그 폴더 안에서 작업합니다. 다른 회사·개인 프로젝트의 문맥을 공통 메모리에 복제하지 않습니다.
5. 결과 파일을 실제로 열어 요청과 맞는지 확인하고, 사용자에게 어디서 열면 되는지 알려 줍니다.
6. 에이전트가 만든 불필요한 임시 파일을 정리합니다. 원본·최종 결과·편집용 파일·재현용 파일·출처를 알 수 없는 파일은 보존합니다.
7. 완료한 프로젝트·이슈를 같은 범위의 보관 폴더로 옮깁니다. 진행 중인 앱·서비스·상위 프로젝트를 통째로 옮기지 않습니다. 옮기기 전에 절대경로에 기대는 손맛·대화 기록과 실행 경로가 있는지 확인합니다.
8. 완료 요약·보관 위치·기존 기록 링크를 남기고 활성 인덱스와 링크를 갱신합니다. 보관한 결과를 다시 찾아 달라는 요청을 실제로 수행해 봅니다.

## 출력

입력·결과 위치, 결과 확인, 정리하거나 보존한 파일, 완료·보관·재조회 증거를 기록합니다. 아직 진행 중인 일은 완료로 옮기지 않습니다.
