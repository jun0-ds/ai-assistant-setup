2. 첫 요청

설치·로그인을 마치고 첫 답변을 받은 에이전트에게 아래 내용을 보냅니다. 지금 쓰는 에이전트와 계정으로 그대로 진행하면 됩니다.

내 Windows 컴퓨터에서 에이전트를 쓰기 위한 세팅을 함께 진행해줘요.

가장 먼저, 설치를 맡길 수 있게 네 권한 설정을 바꿔줘요. Claude Code라면 `~/.claude/settings.json`에서 `permissions.defaultMode`를 `bypassPermissions`로, `skipDangerousModePermissionPrompt`를 `true`로 바꿔요. Codex라면 `~/.codex/config.toml`에 `approval_policy = 'never'`와 `sandbox_mode = 'danger-full-access'`를 넣어요. 다른 설정은 그대로 두고, 설치가 끝나면 안내에 따라 평소 수준으로 조정해요. 바꾼 뒤에는 다시 시작하는 방법을 알려줘요.

https://raw.githubusercontent.com/jun0-ds/ai-assistant-setup/v1.2.1/CONTEXT.md 를 읽고, 라우터가 지정한 현재 단계 문서만 추가로 읽어 진행해줘요. 파일 접근이 필요하면 같은 저장소의 v1.2.1 공개 ZIP을 받아 소스로 사용해요.

나는 에이전트 하나를 설치하고 로그인해서 지금 대화하고 있어요. 먼저 실제 실행파일 위치와 새 PowerShell에서의 인식을 확인해줘요. 설치된 다른 에이전트나 Paseo가 있으면 다시 설치하기 전에 상태를 확인해요.

문턱과 업무·개인 작업공간, Paseo 로컬 사용을 준비해줘요. 다른 기기에서도 쓸지는 내가 이미 말하지 않았다면 필요한 단계에서 물어봐요. 휴대폰은 Paseo QR 연결을 기본으로 쓰고, 어떤 방식이든 이 컴퓨터의 localhost 접속은 유지돼야 해요.

나는 명령어와 컴퓨터 설정을 잘 몰라서 직접 판단하기 어려워요. 설치하면서 묻지 않고 진행하도록 권한을 열어 뒀으니 진단·설치·설정은 알아서 진행하고, 무엇을 했는지만 쉬운 말로 알려줘요. 내 파일 삭제·초기화, 계정 변경, 관리자 권한, 비용이 드는 일처럼 되돌리기 어려운 일만 먼저 쉽게 설명하고 추천 답과 함께 물어봐요.

직접 할 수 있는 진단과 설정은 맡아서 진행하고, 로그인·기기 조작처럼 내가 할 일은 한 번에 하나씩 알려줘요. 오류가 나면 원인을 확인하고 해결한 뒤 같은 검사를 다시 해요. 기존 계정·권한·개인 설정·자료를 초기화하지 말고, 확인 결과와 남은 일을 로컬에 기록해 다음 대화에서 이어갈 수 있게 해줘요.

에이전트가 링크를 읽지 못하면 v1.2.1 ZIP을 받아 압축을 풀고 CONTEXT.md를 읽어 달라고 요청합니다. 인증 없이 받을 수 있는 공개 자료입니다.

처음 한 번 허용하고 다시 시작하기

이 요청을 보내면 에이전트는 먼저 자기 권한 설정 파일을 바꿉니다. 설치를 마칠 때까지 묻지 않고 진행하게 하려는 것입니다. 이때 확인 창이 뜨면 허용(Yes)을 고릅니다. 창이 뜨지 않고 바로 바뀔 수도 있습니다.

바뀐 권한은 에이전트를 다시 시작해야 적용됩니다. 에이전트가 다시 시작해 달라고 하면 아래 순서대로 합니다.

  1. 대화창에 /exit를 입력해 에이전트를 끝냅니다.
  2. 같은 창에서 Claude Code는 claude -c, Codex는 codex resume을 입력합니다. Codex는 최근 대화 목록이 나오면 맨 위 대화를 Enter로 고릅니다.
  3. 이전 대화가 다시 보이면 “다시 시작했어요. 이어서 진행해 주세요”라고 보냅니다.

에이전트가 권한을 바꾸지 못했다면 권한을 직접 설정하려면의 명령을 붙여 넣고 위 순서대로 다시 시작합니다.

에이전트가 물어볼 때

권한을 열어 둔 뒤에는 에이전트가 대부분의 일을 묻지 않고 진행합니다. 내 파일을 지우거나 계정·비용과 관련된 일처럼 되돌리기 어려운 일만 채팅으로 먼저 설명하고 묻습니다. 설명을 듣고 납득되면 안내받은 대로 답합니다.

이해되지 않으면 “이게 뭐예요? 쉽게 설명해 주세요”라고 보냅니다. 그래도 모르겠으면 거절해도 됩니다. 거절해도 그 작업 하나만 실행되지 않을 뿐입니다. 삭제 확인 창이 화면에 직접 뜨면 이해될 때까지 허용하지 않습니다.

중간에 멈췄을 때

준비 폴더와 state/setup-status.md의 위치를 알려 주고 “이 상태를 확인한 뒤 남은 단계부터 이어 가 주세요”라고 요청합니다.
