첫 요청을 받은 에이전트가 읽어요. 현재 상태에 맞는 단계부터 진행하고, 필요한 로그인·기기 조작을 함께해요.

설치 가이드 라우터

Windows 네이티브에서 시작하는 사용자를 돕는 에이전트가 읽는 문서예요. CLI에서 첫 답변을 받기 전이라면 최초 설치부터 안내해요.

입력

읽을 것 범위 목적
사용자 요청 이번 요청 에이전트·모바일 필요 여부·기존 환경을 파악해요.
로컬 state/setup-status.md 있다면 전체 확인한 상태와 실패 지점부터 이어가요.
아래 단계 문서 현재 단계 하나 필요한 참고 문서만 추가로 읽어요.

기본 준비 폴더는 실제 Windows 문서 폴더의 AgentSetup이에요. 그 아래 source/에는 공개 소스, state/에는 사용자 로컬 기록을 둬요. 기존 사용자가 정한 위치가 있으면 유지해요. 로그·개인 경로·상태를 공개 저장소에 커밋하거나 업로드하지 않아요.

진행

사람이 직접 하는 1. 최초 설치와 2. 첫 요청 뒤에 이 라우터를 읽어요. 이후 3~8단계는 상태에 맞춰 선택하고, 이미 끝난 단계와 불필요한 선택 단계는 건너뛰어요. 번호는 위치를 공유하는 기준이며 무조건 모든 단계를 다시 실행하라는 뜻이 아니에요.

현재 상태 읽을 문서 다음으로 넘어갈 증거
시작·명령 미인식·환경 변경 3. 진단 선택한 에이전트의 경로·버전·실제 응답 확인
작업공간 준비 전 4. 작업공간 문턱과 업무·개인 라우팅 작동
Paseo 준비 전·제공자 오류 5. Paseo localhost에서 실제 에이전트 응답
다른 기기도 연결 6. 모바일 다른 기기와 localhost 양쪽 실제 응답
연결 준비 완료 7. 첫 작업 파일 생성·정리·보관·재조회
설치 완료·재개·업데이트 8. 유지 필요한 범위 확인·기존 자료 보존
오류 발생 오류 라우터 원인 확인 후 실패 검사 재수행
  1. 사용자가 준 선택은 다시 묻지 않아요. 모바일이 필요 없으면 해당 단계는 건너뜀으로 기록해요.
  2. 실행 전 실제 환경·파일·설정 값을 읽어요. Windows/WSL, PowerShell/Paseo 데몬은 별도 실행 환경이에요.
  3. 현재 단계의 입력·진행·출력을 따라요. 기존 공식 설치·설정 방법을 먼저 써요.
  4. 설정은 필요한 키만 병합해요. 계정·인증·권한·모델 기본값을 임의로 바꾸거나 파일을 초기화하지 않아요.
  5. 로그인·관리자 조작·기기 조작이 필요하면 사용자가 할 한 가지 행동과 성공 신호를 알려줘요. 인증정보를 채팅에 붙이게 하지 않아요.
  6. 실패·미확인은 통과로 적지 않아요. 미확인에는 누가 어느 기기에서 무엇을 확인할지 써요.
  7. 단계마다 상태를 갱신해요. 재설치부터 반복하지 말고 원인·변경·재검사 결과를 남겨요.

사용자에게 설명하고 묻기

사용자는 명령어·파일 경로·권한 문구를 읽고 스스로 판단하기 어렵다고 전제해요. 승인 창만 띄우거나 명령만 건네면 답할 수 없어요. 아래 세 경우 모두 쉬운 말로 먼저 설명해요.

상황 할 일
승인 창이 뜨는 작업 창의 문구는 에이전트가 바꿀 수 없어요. 실행 직전에 채팅으로 먼저 설명하고, 창에서 무엇을 고르면 되는지 알려줘요.
사용자가 실행할 명령 에이전트가 직접 할 수 없는 일만 부탁해요. 어느 창에 붙여 넣을지, 복사할 명령 하나, 성공하면 보이는 화면, 다른 화면이 나오면 보낼 내용을 알려줘요.
질문·선택 추천 답 하나와 이유를 함께 말해요. 사용자가 판단할 수 없는 기술 선택은 안전한 기본값으로 정하고 무엇을 골랐는지 알려줘요.

설명에는 네 가지를 담아요. 무엇을 하는지, 왜 필요한지, 무엇이 바뀌고 무엇이 그대로인지, 어떻게 답하면 되는지예요. 예를 들면 이렇게 말해요.

지금 Paseo가 이 컴퓨터에 깔려 있는지 확인할게요. 다음 단계를 정하려면 필요해요.
파일을 바꾸지 않고 보기만 해요. 곧 승인 창이 뜨면 허용을 골라 주세요.
  • 쉬운 설명을 먼저 쓰고, 실제 명령·경로는 그 뒤에 덧붙여요. 전문 용어는 일상어로 풀어요.
  • 승인은 설명할 수 있는 작은 묶음으로 받아요. 설명한 범위 안의 작업만 실행하고, 내용이 달라지면 다시 설명해요.
  • 추천은 사실대로 해요. 위험을 줄여 말하거나 승인을 재촉하지 않아요. 삭제·초기화·관리자 권한·방화벽·외부 공개·비용이 드는 일은 되돌리기 어려운 점과 거절하면 어떻게 되는지도 말해요.
  • 앞으로 묻지 않고 허용하는 선택지는 어디까지 열어 두는지 설명하고, 파일을 읽기만 하는 것처럼 안전이 분명한 작업에만 권해요.
  • “모르겠어요”도 정상 답이에요. 더 쉽게 다시 설명하거나 안전한 쪽으로 진행해요. 되돌리기 어려운 일은 사용자가 이해하고 동의하기 전에 진행하지 않아요.
  • 사용자가 거절하면 같은 요청을 반복하지 말고 이유를 듣거나 다른 방법을 설명해요.

출력

로컬 state/setup-status.md에 가이드 버전, 선택 에이전트, 준비 폴더·작업공간·소스 위치, 단계 상태(대기/진행/통과/실패/건너뜀/미확인), 근거와 다음 행동을 기록해요. 실행파일·호스트·포트·진단 결과는 로컬에만 남기고 비밀번호·키·인증 토큰은 기록하지 않아요.

최종 안내에는 다음번에 어디에서 무엇을 실행할지, 파일 위치, 유지할 프로세스와 남은 확인을 적어요.
