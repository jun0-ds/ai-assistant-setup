첫 요청을 받은 에이전트가 읽는 문서입니다. 현재 상태에 맞는 단계부터 진행하며, 필요한 로그인·기기 조작은 사용자와 함께합니다.

설치 가이드 라우터

Windows 네이티브에서 시작하는 사용자를 돕는 에이전트가 읽는 문서입니다. 사용자가 CLI에서 아직 첫 답변을 받지 못했다면 최초 설치부터 안내합니다.

입력

읽을 것 범위 목적
사용자 요청 이번 요청 에이전트·모바일 필요 여부·기존 환경 파악
로컬 state/setup-status.md 있다면 전체 확인한 상태와 실패 지점부터 재개
아래 단계 문서 현재 단계 하나 필요한 참고 문서만 추가로 읽기

기본 준비 폴더는 실제 Windows 문서 폴더 아래의 AgentSetup입니다. 그 아래 source/에 공개 소스를, state/에 사용자 로컬 기록을 둡니다. 사용자가 이미 정한 위치가 있으면 그대로 씁니다. 로그·개인 경로·상태는 공개 저장소에 커밋하거나 업로드하지 않습니다.

진행

사용자가 직접 하는 1. 최초 설치와 2. 첫 요청이 끝나면 이 라우터를 읽습니다. 3~8단계는 현재 상태에 맞춰 고르며, 이미 끝난 단계와 필요 없는 선택 단계는 건너뜁니다. 번호는 위치를 함께 가리키기 위한 기준일 뿐 모든 단계를 처음부터 다시 실행하라는 뜻이 아닙니다.

현재 상태 읽을 문서 다음으로 넘어갈 증거
시작·명령 미인식·환경 변경 3. 진단 선택한 에이전트의 경로·버전·실제 응답 확인
작업공간 준비 전 4. 작업공간 문턱과 업무·개인 라우팅 작동
Paseo 준비 전·제공자 오류 5. Paseo localhost에서 실제 에이전트 응답
Claude·ChatGPT 계정이 모두 있음 Claude·Codex 함께 쓰기 (5단계 안에서) Claude가 Codex에 맡긴 작은 작업 성공
다른 기기도 연결 6. 모바일 다른 기기와 localhost 양쪽 실제 응답
연결 준비 완료 7. 첫 작업 파일 생성·정리·보관·재조회
설치 완료·재개·업데이트 8. 유지 필요한 범위 확인·기존 자료 보존
오류 발생 오류 라우터 원인 확인 후 실패한 검사 재수행
  1. 사용자가 이미 정한 선택은 다시 묻지 않습니다. 모바일이 필요 없으면 해당 단계를 건너뜀으로 기록합니다.
  2. 실행하기 전에 실제 환경·파일·설정 값을 읽습니다. Windows와 WSL, PowerShell과 Paseo 데몬은 서로 다른 실행 환경입니다.
  3. 현재 단계의 입력·진행·출력을 따릅니다. 공식 설치·설정 방법이 있으면 그것을 먼저 씁니다.
  4. 설정은 필요한 키만 병합합니다. 계정·인증·권한·모델 기본값을 임의로 바꾸거나 파일을 초기화하지 않습니다.
  5. 로그인·관리자 조작·기기 조작이 필요하면 사용자가 할 행동 하나와 성공 신호를 알려 줍니다. 인증 정보를 채팅에 붙여 넣게 하지 않습니다. 그 밖의 진단·설치·설정은 맡아서 진행합니다.
  6. 실패하거나 확인하지 못한 항목을 통과로 적지 않습니다. 미확인 항목에는 누가 어느 기기에서 무엇을 확인할지 적습니다.
  7. 단계마다 상태를 갱신합니다. 재설치를 반복하지 말고 원인·변경·재검사 결과를 남깁니다.

맡아서 진행하고 알리기

사용자는 명령어·파일 경로·권한 문구를 읽고 스스로 판단하기 어렵다고 전제합니다. 그래서 첫 요청에서 사용자가 직접 요청한 대로, 에이전트는 설치 기간 동안 묻지 않고 일하도록 자기 권한부터 엽니다(Claude bypassPermissions, Codex approval_policy = 'never'·sandbox_mode = 'danger-full-access'). 방법은 3. 진단의 첫 순서에 있습니다. 5단계에서 Paseo 응답을 확인할 때까지는 진단·설치·설정을 에이전트가 직접 진행합니다. 권한을 연 상태는 5. Paseo의 마지막 순서에서 평소 수준으로 조정합니다.

상황 할 일
진단·설치·설정 묻지 않고 진행합니다. 시작할 때 무엇을 왜 하는지 한두 문장으로 알리고, 끝나면 결과와 바뀐 것을 짧게 알립니다.
사용자가 직접 할 일 로그인·휴대폰 조작·관리자(UAC) 창처럼 에이전트가 대신할 수 없는 일만 부탁합니다. 어느 화면에서 무엇을 누르면 되는지, 성공하면 보이는 화면, 다른 화면이 나오면 보낼 내용을 하나씩 알려 줍니다.
멈추고 묻는 일 권한이 열려 있어도 아래 목록의 일은 실행 전에 채팅으로 설명하고 동의를 받습니다.
기술 선택 사용자가 판단할 수 없는 선택은 안전한 기본값으로 정하고 무엇을 골랐는지 알려 줍니다.

권한이 열려 있어도 실행 전에 멈추고 묻는 일은 아래와 같습니다. 무엇을 하는지, 왜 필요한지, 무엇이 바뀌고 무엇이 그대로인지, 거절하면 어떻게 되는지를 쉬운 말로 설명하고 추천 답을 함께 말합니다.

  • 사용자가 만든 파일·폴더·설정의 삭제·이동·초기화
  • 기존 계정·인증 정보·다른 에이전트 설정의 변경
  • 관리자 권한이 필요한 작업, 방화벽·네트워크 공개 범위 변경
  • 비용이 들거나 외부로 자료를 보내는 일
  • 이 가이드의 단계에 없는 프로그램 설치
지금 예전에 설치된 Codex 폴더를 지워도 되는지 여쭤볼게요. 새 설치와 겹쳐서 헷갈릴 수 있어서예요.
지우면 예전 설정은 사라지고, 그대로 두면 아무것도 바뀌지 않아요. 저는 그대로 두는 쪽을 추천해요.
  • 쉬운 설명을 먼저 쓰고 실제 명령·경로는 그 뒤에 덧붙입니다. 전문 용어는 일상어로 풉니다.
  • 추천은 사실대로 합니다. 위험을 줄여 말하거나 동의를 재촉하지 않습니다.
  • “모르겠어요”도 정상적인 답입니다. 더 쉽게 다시 설명하거나 바꾸지 않는 쪽으로 진행합니다.
  • 사용자가 거절하면 같은 요청을 반복하지 말고 이유를 듣거나 다른 방법을 설명합니다.

출력

로컬 state/setup-status.md에 가이드 버전, 선택한 에이전트, 권한 상태(설치용으로 열림/평소 수준으로 조정함), 준비 폴더·작업공간·소스 위치, 단계 상태(대기/진행/통과/실패/건너뜀/미확인), 근거와 다음 행동을 기록합니다. 실행 파일·호스트·포트·진단 결과는 로컬에만 남기고 비밀번호·키·인증 토큰은 기록하지 않습니다.

최종 안내에는 다음에 어디서 무엇을 실행하면 되는지, 파일 위치, 계속 켜 둘 프로세스, 남은 확인 항목을 적습니다.
