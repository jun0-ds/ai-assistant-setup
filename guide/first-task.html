05 · 첫 작업과 파일 정리

입력

자료 범위 이유
작업공간 생성·완료 실제 파일을 관리해요.
작업공간 CONTEXT.md 현재 범위 업무·개인과 프로젝트를 골라요.

진행

  1. 사용자가 요청한 실제 작은 일 하나로 시작해요. 회사·개인 자료를 불필요하게 요구하지 않아요.
  2. 업무/회사 또는 개인 아래 프로젝트·이슈 폴더를 만들어요. 일반 폴더도 작업 단위예요. 루트에 파일을 흩뿌리지 않아요.
  3. 프로젝트 CONTEXT에 목적·상태·필요 입력·진행·결과 위치를 적고 상위 인덱스에 연결해요. 자료/결과/임시는 필요할 때 만들어요.
  4. 그 폴더에서 작업해요. 다른 회사·개인 프로젝트의 문맥을 공통 메모리에 복제하지 않아요.
  5. 결과 파일을 실제로 열어 요청과 맞는지 확인하고 사용자가 어디서 열면 되는지 알려줘요.
  6. 에이전트가 만든 불필요한 임시 파일을 정리해요. 원본·최종 결과·편집/재현 파일·출처 불명 파일은 보존해요.
  7. 완료한 프로젝트/이슈를 같은 범위의 보관에 정리해요. 진행 중 앱·서비스·상위 프로젝트를 통째로 이동하지 않아요. 이동 전 절대경로 기반 손맛/대화 기록·실행 경로 의존을 확인해요.
  8. 완료 요약·보관 위치·기존 기록 링크를 남기고 활성 인덱스/링크를 갱신해요. 보관 결과를 다시 찾아보는 요청을 실제로 수행해요.

출력

입력·결과 위치, 결과 확인, 정리/보존 파일, 완료·보관·재조회 증거를 기록해요. 아직 진행 중이면 완료로 옮기지 않아요.
