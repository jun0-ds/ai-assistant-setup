첫 요청을 받은 에이전트가 읽는 문서입니다. 현재 상태에 맞는 단계부터 진행하며, 필요한 로그인·기기 조작은 사용자와 함께합니다.

8. 업데이트와 관리

입력

자료 범위 이유
state/setup-status.md 완료·미확인 다음 사용 방법과 남은 확인 설명
작업공간 AGENTS·CONTEXT 유지·라우팅 실제 설치된 계약 사용
오류 안내 해당 증상 실패 지점부터 복구

진행

  1. 다음에는 Paseo를 열고 작업 폴더를 고르면 된다는 것과, 앱이 안 될 때 처음 설치한 CLI를 실행하는 방법을 알려 줍니다.
  2. 그날 첫 작업 때 문턱의 powershell.exe -NoProfile -ExecutionPolicy Bypass -File <작업공간>/.munteok/tools/Check-Updates.ps1 -WorkspaceRoot <경로>를 실행해 새 stable release가 있는지 하루 한 번 확인합니다. 오프라인이어도 작업을 막지 않습니다. 손맛·Paseo의 업데이트는 이와 별개입니다.
  3. 새 버전에서 바뀐 점과 적용 방법을 설명합니다. 개인 데이터·인증·계정·권한은 초기화하지 않습니다. 소스를 갱신하고 설치기를 다시 실행한 뒤 사용자 파일이 보존됐는지 확인합니다.
  4. 도구를 업데이트한 뒤 오류가 나면 해당 단계부터 진단합니다. CLI 바이너리와 Paseo 앱·데몬 환경을 함께 확인합니다.
  5. 원격 사용은 PC 전원·절전·데몬 실행·양쪽 인터넷 상태에 영향을 받습니다. Tailscale을 쓴다면 그 연결도 필요합니다. 자동 시작은 재부팅 뒤 실제로 확인한 범위만 설명합니다.
  6. WSL이 필요하면 이관 안내를 읽습니다. Windows의 인증·설정·실행 중인 프로세스를 그대로 복사하지 않습니다.

출력

다음에 시작할 위치, CLI 복구 방법, 파일 위치, 업데이트 방법, 원격 연결 유지 조건을 짧게 안내합니다. 통과·건너뜀·미확인을 나누고, 미확인 항목에는 대상 기기·담당자·확인할 행동을 적습니다.
